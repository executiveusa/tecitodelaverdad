# TECITO DE LA VERDAD

**Encuentra tu verdad.**

Canonical repository for Tecito de La Verdad — a Mexico City-rooted luxury House of Editions built around finite seasonal tea releases, bilingual truth tags, commissioned hospitality/corporate editions, and nonprofit fundraising collaborations.

## Product thesis

Tecito is not an endless tea catalog. Every tea release is a finite edition with a season, a story, a curated blend, a truth series, and a retirement date.

- Spanish-first, English toggle
- Supplier strategy: Tiesta Tea private label / wholesale, subject to written capability confirmation
- Four seasonal houses: Renacimiento, Fuego, Cosecha, Refugio
- Commissioned editions: hotels, brands/teams, nonprofits
- No fake scarcity, fake inventory, unsupported formulation claims, or vague cause-marketing language

## Run

```bash
npm install
npm run dev
```

## Quality system

The build uses three external skill references:

- Emil Kowalski `skills`: design engineering, motion restraint, responsive feedback, invisible-detail polish
- `i-have-adhd`: action-first, obvious hierarchy, low cognitive load, short paths to value
- `gauntlet-loop`: separate builder/critic, named fetchable comparison bar, blind A/B, loop until ours wins

The current visual comparison bar is Bellocq Tea Atelier's live homepage at desktop and mobile, while remaining original to Tecito's Mexico City identity.
